# NUMBERS: every number shown on the Home, Overview, Results, Run it (stored values), Compare with MATLAB and Code pages of the site, and where it comes from

Section names in the table below map to pages: hero, stat row, main chart, sections 1 to 4 and figures = the Window replay page (/replay/, hero, cards) and All result tables (/results/); "home scene" = the Home car scene (/, built by demo_v2/build_home.py); "overview 1" to "overview 15" = the fifteen chapters of Overview (/overview/, built by demo_v2/build_overview.py); section 5 = /matlab/; section 6 = /run/ (MATLAB windows) and /code/. Every page is generated by `demo_v2/build_site.py` from `demo_v2/templates/`, which parses the result files named below at build time and writes the numbers into the page; none is typed by hand. Re-run the script after any result file changes.

The sections "Run it yourself" and "Train it yourself" show numbers computed live in the visitor's browser, beside the stored values from `demo_v2/data/reference.json` (built by `demo_v2/export_data.py` from the CSV files listed there) and `demo_v2/data/ml_reference.json` (paper fold-0 values from `results/ml/*.json` and CSVs).
